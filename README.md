# Zombie Coop FPS

Кооперативный зомби-шутер от первого лица на разделённом экране. Чёрно-белый мир, красная только кровь. Игроки пробиваются к выходу из здания, а зомби разваливаются по-разному в зависимости от того, куда попала пуля.

![Прототип: двое игроков на разделённом экране](docs/screenshot.png)

План и дизайн: [документ с планом](https://claude.ai/artifact/KrgDqyad3fy6bYMVxXTXwv).

## Что уже есть (прототип)

- Разделённый экран на двоих, у каждого своя камера, фонарик и интерфейс.
- Зомби из простых блоков с 6 зонами попадания: голова (×3 урона, мгновенная смерть), торс, две руки, две ноги.
- Отрыв частей тела: оторванная часть улетает с кровавым следом, на теле остаётся красный обрубок. Без ноги зомби ползёт, без рук бьёт слабее.
- Кровь на полу и стенах по направлению выстрела, короткая пауза (hit-stop) на убийстве.
- Нуар-фильтр: всё серое, кроме крови, плюс контраст, зерно и виньетка.
- Звуки синтезированы кодом, без сторонних файлов: выстрел, мокрое попадание, хруст при отрыве, стоны и рык зомби, удар по игроку, щелчки перезарядки.
- Мягкий aim assist для геймпада, подъём упавшего напарника, волны зомби в тестовой комнате.

Процедурные этажи, другие виды оружия и типы зомби — следующие этапы по плану.

## Запуск

Нужен [Godot 4.3](https://godotengine.org/download) или новее. Откройте папку проекта в Godot и нажмите F5.

## Управление

| Действие | Игрок 1 | Игрок 2 |
| --- | --- | --- |
| Ходьба | WASD или левый стик геймпада 1 | Левый стик геймпада 2 |
| Обзор | Мышь или правый стик | Правый стик |
| Выстрел | Левая кнопка мыши или правый курок | Правый курок |
| Перезарядка | R или кнопка X | Кнопка X |
| Поднять напарника | Подойти к упавшему и постоять 3 секунды | То же |

Клик по окну захватывает мышь, Esc отпускает.

## Структура

```
scenes/main.tscn          точка входа
scripts/main.gd           разделённый экран, общий 3D-мир, перезапуск
scripts/player.gd         игрок: движение, прицел, стрельба, падение и подъём
scripts/zombie.gd         зомби: зоны попадания, отрыв частей, смерть
scripts/gore.gd           кровь, пятна, отлетающие части, hit-stop
scripts/sfx.gd            звуки, синтезированные кодом
scripts/zombie_spawner.gd волны зомби
scripts/test_room.gd      тестовая комната (заменится генератором этажей)
scripts/player_hud.gd     интерфейс половины экрана
shaders/noir.gdshader     ч/б фильтр с красной кровью
tests/smoke_test.gd       проверка без окна
tests/screenshot.gd       снимок экрана для документации
```

## Проверка

```
godot --headless --path . -s tests/smoke_test.gd
```

Проверяет, что сцена запускается, выстрел в голову убивает, отрыв ноги заставляет ползти, а торс выдерживает 4 попадания.
