# Сборки Zombie Coop FPS

Готовые сборки на Godot 4.3. Скачать файл: открой его на GitHub и нажми **Download raw file** (или кнопку ⬇).

| Платформа | Файл | Как запустить |
|---|---|---|
| macOS (Intel и Apple Silicon) | `ZombieCoopFPS-macOS.zip` | распаковать, запустить `Zombie Coop FPS.app` (см. ниже про Gatekeeper) |
| Windows 10/11, 64 бит | `ZombieCoopFPS-Windows-x64.zip` | распаковать, запустить `ZombieCoopFPS.exe` |
| Linux x86_64 | `ZombieCoopFPS-Linux-x64.tar.gz` | `tar xzf ZombieCoopFPS-Linux-x64.tar.gz && ./ZombieCoopFPS.x86_64` |
| Браузер | `ZombieCoopFPS-Web.zip` | распаковать и открыть через локальный сервер (см. ниже) |

Управление: игрок 1 — клавиатура и мышь, остальные — геймпады (до 4 игроков).

## macOS: первый запуск неподписанной сборки

Сборка подписана только «ad-hoc», без сертификата Apple, поэтому macOS при первом запуске скажет, что не может проверить разработчика. Обойти один раз любым способом:

1. **Через настройки (macOS 15 Sequoia и новее).** Дважды кликни по приложению, закрой предупреждение. Открой **Системные настройки → Конфиденциальность и безопасность**, прокрути вниз до сообщения про «Zombie Coop FPS» и нажми **Всё равно открыть**, подтверди паролем.
2. **Правый клик (macOS 14 и старше).** Правый клик (или Ctrl+клик) по `Zombie Coop FPS.app` → **Открыть** → **Открыть**.
3. **Через Терминал (работает везде).** Снять карантин с распакованного приложения:
   ```sh
   xattr -dr com.apple.quarantine "/путь/к/Zombie Coop FPS.app"
   ```
   Удобно: напиши `xattr -dr com.apple.quarantine ` и перетащи приложение в окно Терминала.

Дальше игра запускается обычным двойным кликом. Если macOS пишет, что приложение «повреждено», это тот же карантин, помогает способ 3.

Перенеси приложение в «Программы», если хочешь, но сначала распакуй zip (Safari распаковывает сам).

## Браузерная версия

Браузер не открывает игру с диска (`file://`), нужен любой локальный сервер:

```sh
unzip ZombieCoopFPS-Web.zip -d zombie-web
cd zombie-web && python3 -m http.server 8000
```

и открыть http://localhost:8000. Сборка без многопоточности, поэтому особые заголовки сервера не нужны: её можно выложить на GitHub Pages или itch.io как есть. В браузере используется упрощённый рендер (Compatibility), геймпады работают в Chrome.

## Как пересобрать

Нужны Godot 4.3 и шаблоны экспорта 4.3 (в редакторе: **Editor → Manage Export Templates → Download**). Потом:

```sh
GODOT=/Applications/Godot.app/Contents/MacOS/Godot tools/export_all.sh
```

Или в редакторе: **Project → Export…**, пресеты Windows, macOS, Linux и Web уже настроены.

## Чего нет

- **Android** — нужен Android SDK и ключ подписи; можно добавить отдельно.
- **iOS** — экспорт возможен только на Mac с Xcode и аккаунтом Apple Developer.
